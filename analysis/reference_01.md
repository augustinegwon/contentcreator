# 레퍼런스 영상 분석 - reference/reference_01.mp4

> 이 파일은 `build_md.py`로 JSON에서 자동 생성됨. 수정은 JSON에서 할 것.

- 분석 방법: 프레임 추출(2초 간격 + 전환 구간 0.5초 간격) / 색상 샘플링 / 오디오 음량 측정
- 정확도: 시간은 2초 간격 샘플 기준이라 ±1초 오차가 있음. CapCut 수치(밝기, 스케일 등)는 '측정값'과 '추정값'을 구분해서 표기. 메뉴 이름은 CapCut 버전에 따라 조금 다를 수 있음.
- 개인정보: 레퍼런스 영상 속 실명·날짜는 <신랑>, <신부>, <날짜> 같은 자리표시자로 바꿔 저장함.

## 영상 개요

- 길이: 156초 / 24fps
- 캔버스: 9:16 세로 (측정 720x1280, 내보내기는 1080x1920 권장)
- 구조: 인스타 릴스/스토리형 세로 영상 안에 16:9 가로 영상 창을 넣은 구조
- 편집 툴: CapCut Desktop (Mac)

## 전체 분위기·스타일

- **분위기**: 차분하고 감성적인 다큐 느낌. 어린 시절 → 연애 → 웨딩 촬영으로 이어지는 시간순 구성
- **BGM**: 영어 팝 발라드 (곡명 미확인). 0~48초 잔잔(약 -19dB) → 48초부터 커짐(약 -14dB) → 94~104초 브레이크다운으로 작아짐 → 112초부터 다시 큼 → 약 146초에 끝나고 이후 약 9초 무음
- **색감**: 배경은 매우 어둡고, 가운데 창만 밝게 보이는 대비. 사진은 원본 필름/빈티지 색감 그대로 사용(별도 보정 거의 없음)
- **폰트**: 상단 문구: 가는~중간 두께 고딕(한글). 날짜·영문 캡션·OUR MEMORY·영문 가사: 고급스러운 세리프체. 한글 가사: 가는 고딕, 흰색. 영문 가사: 골드색 세리프
- **편집 리듬**: 가사 한 구절(약 3~4초)마다 사진/컷이 바뀜. 전환은 대부분 짧은 디졸브와 검정 경유(Dip to black). 사진은 느린 줌인으로 정지된 느낌을 없앰

## CapCut 공통 레시피

_아래 메뉴 이름은 영문 CapCut 기준. 한글판에서는 이름이 다를 수 있으니 괄호 안 한글 이름이나 검색창으로 찾을 것._

### `base_canvas` - 공통 베이스 (영상 전체 길이로 깔아두는 고정 레이어)

1. 새 프로젝트를 만들고 프리뷰 우하단 Ratio(비율)를 9:16으로 바꾼다. 내보내기는 1080x1920, 24fps(레퍼런스가 24fps).
2. 배경: 잔디 위 안개꽃(+리본) 사진 1장을 맨 아래 트랙에 놓고 영상 전체 길이로 늘린다. 우측 패널 Adjustment(조정)에서 Brightness(밝기)를 크게 낮춘다 (추정: -40~-60). 가운데 창이 돋보이게 하는 역할이다.
3. 상단 문구: Text → Default text로 2줄을 입력하고 중앙정렬. 1줄은 얇게, 2줄은 조금 굵고 크게. 흰색. 위치는 화면 세로 약 27~30% 지점.
4. 하단 OUR MEMORY 로고: CapCut에는 같은 모양이 없으니 Canva 등에서 투명 PNG로 만들어 Media로 가져온다. 화면 세로 약 72%, 가로 중앙, 폭 약 19%.
5. 위 3개는 한 번만 만들고 길이를 영상 끝까지 늘려두면 이후 장면에서 건드릴 일이 없다.

### `video_window` - 가운데 16:9 영상 창 + 검정 바탕 + 고정 글씨

1. 소스 클립(16:9)을 배경 위 트랙에 올리고 우측 Basic에서 Scale을 약 96%, Position은 0/0으로 둔다 (측정: 창 너비 692/720 = 96%, 세로 정중앙).
2. 검정 바탕: Media → Library(라이브러리)에서 Black(검정) 클립을 배경 위 트랙에 전체 길이로 놓는다. Mask → Rectangle(직사각형)로 창과 같은 크기(가로 96%, 세로 약 30%)로 잘라 맞춘다. 사진 장면에서 검정 배경이 되는 층이다.
3. 창 안쪽 고정 글씨 2종을 만든다. 'OCTOBER 10, 2026'(창 상단 중앙)과 영문 2줄 캡션(창 하단). 작은 세리프체 흰색으로 만들고 전체 길이로 늘려 항상 맨 위 트랙에 둔다.
4. 세로로 촬영한 소스는 창에 맞게 Scale을 줄이거나 Crop(자르기)한다.

### `feather_photo` - 가장자리가 번지는 사진 (검정 바탕 위 비네팅 느낌)

1. 사진 클립을 검정 바탕 위 트랙에 놓는다.
2. 우측 패널 Mask → Rectangle(직사각형)을 적용하고 Feather(페더) 슬라이더를 올려 가장자리를 번지게 한다. 모서리 둥글기도 약간 준다.
3. 두 장을 나란히 놓을 때는 각 사진의 Position X를 약 ±25%로 나누고, 두 번째 사진은 1초쯤 늦게 시작해서 Animations → In → Fade In(0.5초)을 준다.

### `blur_bg` - 사진 뒤에 어둡게 번진 같은 사진 배경 (벚꽃 장면 등)

1. 사진 클립을 선택하고 Basic 아래 Background(배경) → Blur(블러)를 켠다. 또는 같은 사진을 한 장 더 복제해 아래 트랙에 확대 + 블러 + 밝기 낮춤으로 깐다.
2. 위 사진에는 feather_photo의 Feather 마스크를 준다. (원본 배경이 같은 사진을 확대한 것인지는 추정)

### `slow_zoom` - 정지 사진에 느린 줌인 (Ken Burns)

1. 사진 클립의 첫 프레임에서 Basic → Scale 옆 키프레임(◆) 버튼을 눌러 100%로 고정한다.
2. 마지막 프레임으로 이동해 Scale을 108~115%로 올리면 키프레임이 자동 생성된다 (추정: 원본은 약 10% 안팎의 느린 줌).
3. 움직임이 딱딱하면 Animations → Combo 또는 In의 Zoom In 계열로 대체해도 된다.

### `dip_to_black` - 검정을 거치는 전환 (Dip to black)

1. 앞 클립 끝에 Animations → Out → Fade Out(0.5~1초), 뒤 클립 시작에 Animations → In → Fade In(0.5초)을 준다.
2. 창 뒤에 검정 바탕 클립이 깔려 있어야 배경 잔디가 아니라 검정으로 보인다. (video_window의 검정 바탕 참고)
3. 또는 Transitions에서 Fade/Dissolve 계열을 쓰거나 Opacity 키프레임 100→0→100으로 직접 만들어도 된다.

### `dissolve` - 디졸브 (이어지는 두 클립이 겹쳐지며 바뀜)

1. 같은 트랙에서 붙어 있는 두 클립 사이 경계를 클릭하고 Transitions → Basic 계열의 Dissolve(또는 Cross dissolve)를 적용한다.
2. 길이는 0.5~1.0초로 맞춘다 (원본 추정: 사진 사이는 약 0.5초, 장면 사이는 약 1초).

### `film_strip` - 필름 스트립 (KODAK PORTRA 400) 가로 스크롤

1. 검정 바탕 위에 사진 3~4장을 서로 다른 트랙에 올린다. 가운데 사진이 창 너비의 약 50%, 양옆 사진은 일부만 보이게 가로로 나란히 배치한다. 사진 사이는 검정 간격(필름 프레임처럼).
2. 스크롤: 각 사진의 Position X에 키프레임을 3개 준다. 오른쪽에서 들어옴 → 가운데에서 약 3초 머묾 → 왼쪽으로 나감. 사진 하나당 이동은 약 1초. 모든 사진이 같은 타이밍으로 같이 움직여야 하나의 필름처럼 보인다.
3. 움직임이 딱딱하면 키프레임에서 Ease in/out(이징)을 켠다 (버전에 따라 키프레임 커브 메뉴가 없을 수 있음).
4. 고정 글씨: 'KODAK PORTRA 400'(창 좌상단·우상단·하단 중앙), '22A'(창 상단 중앙·하단 좌우). 굵은 산세리프 흰색, 아주 작게. 사진은 움직여도 글씨는 고정.
5. 사진은 원본 필름 색감을 살린다. 보정이 필요하면 Adjustment에서 Saturation(채도)만 약간 조절.

### `camcorder` - 캠코더(VHS) 화면 효과

1. 사진 또는 영상에 Filters/Effects에서 'VHS', 'Camcorder', 'DV', 'REC' 등으로 검색해 캠코더 틀 효과를 찾아 올린다. 원본은 모서리 프레임 + 'PLAY ▶' + 빨간 점 'REC' 구성.
2. 효과에 없는 글씨는 직접 만든다. 좌하단 'PM 03:58 / JAN. 29 2026'(날짜·시간), 우상단 타이머 '00:03', '00:04'. 고정폭 느낌의 산세리프 흰색. 타이머는 1초마다 텍스트를 바꾸는 방식(1초짜리 텍스트 여러 개).
3. 색감: 세피아에 가까운 따뜻한 노란 톤. Adjustment에서 Temp(색온도)를 올리고 Saturation을 낮추거나 Vintage 계열 필터 사용. 사진 가장자리는 feather_photo처럼 번지게.

### `lyric_captions` - 가사 자막 (한글 흰색 + 영문 골드)

1. 먼저 BGM을 타임라인에 올린다. 모든 컷 타이밍의 기준이 된다.
2. Captions(자막) → Auto captions(자동 캡션)로 영어 가사를 뽑고 어긋난 부분은 직접 고친다. 또는 가사를 SRT 파일로 만들어 Captions의 Local captions/가져오기로 넣는다.
3. 각 자막 안에서 한글 번역을 첫 줄, 영문을 둘째 줄로 줄바꿈한다. 영문 줄만 색을 골드로 바꾼다 (샘플링: 약 #AFA66A~#C5C07D).
4. 스타일은 한 번 만든 뒤 모든 자막에 적용한다 (Apply to all 계열 버튼). 위치는 창 하단, 화면 세로 약 59~61%.
5. 자막은 약 3~4초마다 바뀐다. 각 구절 길이에 맞춰 사진 컷도 같이 자르면 레퍼런스처럼 리듬이 맞는다.

### `band_collapse` - 영상 창이 위아래에서 가운데 선으로 접히는 엔딩

1. 마지막 영상 클립에 Mask → Rectangle(직사각형)을 적용한다.
2. 마스크의 Height(세로 크기) 키프레임을 만든다. 시작 100%에서 끝 0%로, 약 3초 동안 줄인다. 위아래가 동시에 가운데로 모이도록 마스크 중심은 창 중앙에 둔다.
3. 마스크 키프레임이 안 되는 버전이면 Basic → Scale 대신 Crop(자르기) 위치를 키프레임으로 움직이거나, 클립 위에 검정 박스 2개(위·아래)를 가운데로 이동시키는 방식으로 대체한다.

## 장면별 편집 방법

### 1. 오프닝 - 석양 바다 (00:00~00:09)

노을 진 바다에서 실루엣의 신랑신부가 서 있다가 포옹(약 4~8초). 창을 가득 채운 영상 클립.

- **전환(들어올 때)**: 시작부터 바로 보임
- **전환(나갈 때)**: 약 8.5~9초에 어둡게 꺼지며 검정으로 이어짐 (Dip to black)
- **모션**: 원본 영상의 움직임 그대로
- **텍스트**: 좌: <신랑 한글명> + 영문명 / 우: <신부 한글명> + 영문명 / 가운데: 흰 하트(♥) / 애니메이션: 이름은 페이드 인. 신부 이름과 하트는 약 2초에 등장 (추정) / 위치: 창 세로 중앙보다 약간 위, 좌우로 넓게 벌려서 배치. 한글 위, 영문 아래의 2줄, 아주 작게
- **색감·필터**: 골든아워 오렌지. 별도 필터 없이 원본 색
- **속도**: 1x
- **오디오**: BGM 시작. 가사 자막은 아직 없음
- **사용 레시피**: `base_canvas`, `video_window`, `dip_to_black`

**CapCut 작업 순서**

1. base_canvas와 video_window로 공통 층을 먼저 만든다.
2. 석양 영상 클립을 창에 맞춰(Scale 약 96%) 0초부터 9초까지 놓는다.

### 17. 엔딩 - 결혼 문구 + 창이 접히며 암전 (02:26.5~02:36)

## 나중에 참고할 팁

- 작업 순서: ① BGM 배치 → ② 가사 자막(타이밍 기준) → ③ 공통 베이스 3종(배경, 상단 문구, 로고) 전체 길이로 고정 → ④ 창 안 고정 글씨와 검정 바탕 → ⑤ 사진·영상을 가사 구절에 맞춰 배치 → ⑥ 전환·줌·효과 → ⑦ 엔딩.
- 고정 층(배경, 문구, 로고, 창 안 글씨)은 맨 처음에 전체 길이로 만들어두면 이후 장면 작업이 사진 교체만으로 단순해진다.
- 장면 종류는 크게 5가지다: ① 풀 영상 클립 ② 풀 사진 + 느린 줌 ③ 검정 위 번지는 사진 ④ 필름 스트립 ⑤ 캠코더. 처음 3개는 거의 같은 레시피이고 ④, ⑤만 별도 공을 들이면 된다.
- 사진 컷 길이는 가사 한 구절(약 3~4초)이 기본. 같은 사진을 길게 쓸 때(소파 장면 약 10초)는 줌인으로 지루함을 없앤다.
- 시간순 스토리 구성: 오프닝(영상) → 부모님 결혼사진 → 유년기 → 연애 → 여행 → 웨딩촬영 → 날짜 풍선 → 엔딩 문구. 영상 길이 약 2분 36초.
- BGM 에너지 설계: 앞쪽 잔잔(유년기) → 약 48초에서 커지며 연애 사진 시작 → 중간 브레이크다운(캠코더) → 후렴 → 정적 속 엔딩 문구.
- 여러 사진이 같은 스타일로 보이려면 번짐(Feather) 값, 줌 비율, 전환 길이를 한 번 정해서 복사해 쓴다.
- 원본 영상 소리는 모두 끄고 BGM만 쓴다 (측정상 음량이 일정함).
- 배경·로고용 이미지는 CapCut 안에서 만들기 어려우므로 Canva에서 PNG로 미리 만들어 가져온다.
